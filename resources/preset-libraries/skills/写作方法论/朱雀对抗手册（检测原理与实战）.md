## 检测器在看什么（六个判定维度）
1. **困惑度**：文本越「可预测」越像 AI——AI 总是选最大概率的下一个词，人类会写出「意外」的词
2. **爆发度**：人类句子长短参差（CV 大），AI 句长均匀、段落工整
3. **语义连贯**：AI 过于连贯从不跑题；人类会插话、跑题、自我修正
4. **修辞多样性**：AI 修辞工整化——优雅排比是重灾区，实测 100% 判 AI
5. **术语密度**：AI 爱堆抽象名词与概念（格局 / 赋能 / 闭环）
6. **情感一致性 + 词汇特征库**：AI 私加人设、情绪平滑无毛边；特征库抓高频毒句式

## 实测结论（1400 条真人众测反馈）
- 删词式去味基本无效：特征库匹配只是小头，困惑度才是大头
- 「优雅」就是 AI 味：越工整越可疑，参差才像人
- 注入人类信号实测有效：具体性是降困惑度最狠的一招
- AI 不会玩梗：硬学句式的笑话一眼假（好笑程度和冒犯性成正比，AI 不敢冒犯）
- AI 幻觉数据是强信号：「某报告显示」「NASA 算了一笔账」——查无实据一律删

## 六大人类信号权重表
| 信号 | 权重 | 注入方法 |
|---|---|---|
| 具体性 | 0.30 | 千字 6 处：人名 / 数字 / 年份 / 地名 / 专名 |

## 文章专属鉴定信号（一眼 AI）
科普起手式（先说答案 / 掰开了揉碎了 / 你品一下）｜三字鉴定词（声音很平 / 目光一凛 / 指节泛白）｜莫名其妙的比喻（本体喻体无生活逻辑关联：命运的齿轮 / 如潮水般涌来）｜假精确数字（0.3 秒 / 一步 50cm）｜讨好腔（稳稳接住你 / 你的观察很敏锐）｜自问自答老师腔（说明什么？说明…）｜「你以为A，实际上B」｜升华套话（影响深远 / 意义重大 / 在当今…的时代）

## 实战流程
1. 写作台「去AI味」面板看人类信号密度（本地实时打分，不耗 token）
2. 红牌先拆——诊断报告里 R 编号最优先
3. 按需选改写强度 L1-L4（注入式，不是删词式）
4. 分清规则：网文正文用「小说正文」，公众号 / 评测 / 科普用「文章」
5. 定稿前去朱雀官网实测校准——本手册与面板分数都只是自检指引，最终以检测器实测为准
