## 核心方法论：删词无效，注入有效
检测器看的是困惑度与句长爆发度，不是词表。删掉几个 AI 高频词基本不降分；塞入「只有人类才会写」的具体信号才有效。实测：工整优雅的排比 = 100% 判 AI。

## 红牌毒句式（出现即修，最高优先）
| 毒句式 | 修法 |
|---|---|
| 不是A，而是B（含「不是X。不是Y。只是Z」变体） | 删前半句直接写B，或改「不仅是A更是B」 |
| 同构排比三连 / 有的…有的…有的 | 保留最强一条，其余改写成参差散句 |
| 眼中闪过一丝 / 嘴角勾起一抹 | 他垂下眼 / 他笑了一下，没到眼底 |
| 心中涌起一股 / 心头一震 | 用身体反应：手在抖 / 攥紧拳头 |
| ，带着一丝… | 拆短句或换动作 |
| 深吸一口气 | 换成具体动作 |
| 仿佛 / 犹如…一般 | 没有真实生活逻辑就删，改白描 |
| 不容置疑 / 不易察觉 | 直接写声音、动作特征 |

## 六维人类信号（怎么注入）
1. **具体性**（权重 0.30）：关键结论后补一件具体小事——人名 / 数字 / 地点，千字 6 处满分。降困惑度最狠的一招
2. **爆发度**（0.22）：必须有 10 字内短句，也允许一口气 40 字以上的长句；句长落差 CV≥1.0 满分，0.6 及格
3. **疑虑**（0.13）：小说正文只准放在角色台词里（说实话 / 拿不准 / 谁知道呢）
4. **口语**（0.13）：台词像活人——啥 / 咋 / 你别说 / 答非所问 / 话说一半
5. **离题**（0.12）：插一句不相干的真实小事再拉回来
6. **不完美**（0.10）：碎片句、断尾、允许一处不完美的表达

## 正文 vs 文章两套纪律
- **小说正文**：叙述者不许跳出来；疑虑 / 口语 / 跑题只进对话层；对话占两到四成；对话行天然短，别把叙述句也写成短句堆
- **文章**：删机械连接词（首先 / 其次 / 综上所述）；允许作者第一人称自我怀疑；毒句式换论说版（值得注意的是 / 不可否认 / 在当今…的时代 / 你以为A实际上B / 自问自答老师腔 / 假精确数字）

## 强度分级（对应去AI味面板 L1-L4）
L1 只拆红牌 → L2 加句长落差 → L3 加具体小事 + 自我怀疑（台词内）→ L4 加离题闲笔 + 断尾 + 口语词

## 通用约束
- 每段最多一个转折词；相邻段落长度差至少 2 倍
- 允许一段话悬着结束，不要每段都总结收尾
- 读起来像金句的句子，重写它
- 叙事文本至少一处具体感官细节，允许跳跃与留白

## 22 模式清单（文章类补充自查）
- 一级：夸大意义（标志着 / 见证了）｜否定式排比（不仅…而且）｜三段式列举｜句末分词假装深度（彰显 / 突出）｜知名度堆砌｜广告腔（充满活力的）｜协作痕迹（希望对您有帮助）｜公式化展望
- 二级：高频词（此外 / 至关重要 / 深入探讨 / 格局）｜回避系动词「是」｜模糊归因（专家认为）｜同义词循环｜虚假范围（从X到Y）｜破折号滥用｜粗体滥用｜内联标题列表
- 三级：填充短语（为了实现这一目标）｜过度限定（也许 / 某种程度上）｜通用积极结论｜截止日期免责｜谄媚语气｜表情符号装饰
