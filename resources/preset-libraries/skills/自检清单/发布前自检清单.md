## 每章发布前

- [ ] 时间线没有跳跃矛盾（本章距离上章过了多久，明确）
- [ ] 每个出场角色都有存在意义（推动剧情 / 提供信息 / 制造情绪，至少占一样）
- [ ] 章末有钩子（对照「章末断章五类」）
- [ ] 无大段总结式说教；对话占比不低于三成
- [ ] 错别字高危词扫一遍：的地得、重复用字、同音错字
- [ ] 手机端预读开头 300 字，决定是否删掉第一段
