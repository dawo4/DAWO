# DAWO

一款免费、本地优先的长篇网文写作桌面软件。整合工作流式逐章生成、九大结构化资料板块、可审阅的智能体系统与去 AI 味工具链，面向十万字以上的长篇创作。

> 无账号 · 无云端 · 无广告 —— 所有数据都是你磁盘上的 Markdown 和 JSON 文件。

![主页](resources/marketing-shots/01-主页.png)

## 核心能力

**资料即地基**：时间线、故事线、角色关系图、卷章细纲、专名词典、伏笔登记、境界体系、出场追踪、地图路线图九大结构化板块，全部配套专用智能体与读写工具，全局搜索全量索引，写作台右栏随写随查。不够用？资料区两步向导自建专属面板，字段自己定，智能体照样能读写。

**智能体可审阅**：十五个内置智能体（大纲、分节写手、设定、时间线、伏笔管理、拆书、资源管家等），所有写入走提案制——AI 提交差异预览，你点了才落库，增量合并且可反悔。一句话创建自定义智能体，目录、板块、面板、联网、分配五类权限逐项勾选；支持圆桌接力与主从分配两种多智能体协作，长对话自动压缩不断片。

**作者记忆**：全局与书籍两层记忆条目化存储，跨书偏好与单本剧情决策分开管；智能体开口前先读你立过的规矩，也能自己写记忆（出审阅卡），攒多了 AI 一键整理。

**创作工作流**：一键建书 → 生成设定集 → 分卷大纲 → 逐章生文。长篇做了保守裁剪注入（大纲按卷切、角色卡按出场切）、伏笔板整板硬约束、细纲板全文存档复用、字数反推章数；推理模型思考期实时显示，60s/150s 看门狗防假死。

**任务九通道**：灵感取名、建书大纲、逐章正文、拆书登记、续写、润色、去 AI 味、划词、智能体对话，九条 AI 通道各配各的模型——大纲用好模型，三百章正文换便宜的，支持一键应用到全部，老配置自动继承。

**去 AI 味**：正文/文章两套文体规则，22 种 AI 指纹三级诊断，L1-L4 四档改写强度；面板内置六维人类信号打分器（具体性/爆发度/疑虑/口语/离题/不完美），本地实时算分零 token，判词词库外置可自己加词。

**拆书**：贴文本或直接导入 TXT/MD，按章数分五档精细度（5 章精拆，30 章也能拆），报告必须附原文证据，自动沉淀进素材库，可复用套路一键提炼成技能。

**外观**：六套书墨风主题、圆角字号可调、本地背景图、全套动效开关，滚动条悬停浮现不占布局。

## 下载安装

前往 [Releases](../../releases) 下载最新 `DAWO Setup x.x.x.exe`（Windows 10/11，未签名，首次运行若被 SmartScreen 拦截选「仍要运行」）。

- 0.2/0.3 老用户直接覆盖安装，书稿与配置原地保留
- 新用户装完先到「设置 → AI 服务」配一个 OpenAI 兼容服务商（DeepSeek、Kimi、智谱、通义、MiMo、OpenAI、Ollama 本地等均可），Key 只存在本机

## 数据与隐私

- 每本书一个文件夹，正文 Markdown + 资料 JSON，删软件文件还在
- AI Key 只存本地、不经过任何中间服务器；调用记录（模型/耗时/token）全部可查
- 正文大改动自动快照，支持整书备份恢复

## 技术栈

Electron 33 · electron-vite 2 · Vue 3 + TS + Pinia · Tailwind 4 · TipTap 2 · vue-flow · docx

```bash
npm install
npm run dev     # 开发

```
